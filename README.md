Al principio olvidé utilizar GitHub para llevar el control de versiones del proyecto T-T, así que desarrollé el código localmente y fui guardando diferentes versiones en mi computador a medida que avanzaba, sin sobrescribir los archivos anteriores. Después recordé que podía subir las modificaciones progresivamente mediante commits, por lo que decidí configurar el repositorio y organizar allí los avances del proyecto.
